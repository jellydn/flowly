Why Flowly

An agent you can verify, not blindly trust.

Every claim traces to a file the agent actually read. When the evidence isn't there, it says so.

📄

Grounded answers, always cited

No free-association. Each answer names the exact file and line range it read, so you can confirm the claim in seconds.

file-and-line citations
🙅

Honest about what it doesn't know

Asked about payment processing in a repo that has none, it reports insufficient evidence instead of inventing one.

no hallucinated answers

How it works

Plan. Observe. Reflect. Answer.

Three meta-tools structure the loop; five read-only tools do the work, all within one shared budget.

🧭

1 · Plan

Declare a 3–5 step plan before touching a single tool. Budget-free.

🔎

2 · Observe

Search docs, search code, retrieve, then read the strongest candidates.

✅

3 · Reflect & answer

Enough evidence? Answer with citations. Otherwise replan and dig once more.
